# Santhosh Kumar S — Portfolio

Open the site by opening `index.html` in a browser. The project is static — no build step required.

Files:
- `index.html`, `about.html`, `projects.html`, `contact.html` — Pages
- `styles.css` — Styling (responsive, accessible)
- `script.js` — Accessible form validation and announcements

Appearance:
- Dark theme is applied by default across all pages and contents.
- A light theme is available via the header `Toggle theme` button; the choice is saved to `localStorage`.

Accessibility & SEO:
- Semantic HTML5 elements used (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`, `form`).
- ARIA attributes and roles added for improved screen-reader experience.
- Meta tags added for SEO and sharing.

To test locally:
1. Open `index.html` in your browser.
2. Navigate with keyboard (Tab) to verify focus states.
3. Submit the contact form to see accessible status messages.
